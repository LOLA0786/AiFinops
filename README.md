# 🚀 AiFinOps — The Autonomous GPU + Cloud Cost Platform

AiFinOps is an **AI-driven FinOps + GPU optimization autopilot** for AWS, GCP, Azure, Kubernetes, and on-prem clusters.

## ✅ What it does
- **Cloud Cost Intelligence** (AWS/GCP/Azure)
- **GPU Waste Killer** (idle GPUs, zombie pods, runaway training loops)
- **Kubernetes GPU Insights** (Ray, Kubeflow, EKS, GKE, AKS)
- **Anomaly Detection + Forecasting**
- **Auto-Fix PR Generator** (GitHub integration)
- **Multicloud Autoscaler**
- **GPU Marketplace** — find cheapest GPU across clouds
- **Agent Installer** (1-line `curl` install)
- **Terraform Infra Kit** — deploy anywhere
- **Pre-commit + CI DevOps Pipeline**
