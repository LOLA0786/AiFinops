# Open-Source Bait Strategy

Goal: open-source monitoring & GPU collection core to build community adoption.
- Offer core collectors, dashboard panels, and exporters under MIT/Apache.
- Keep automation modules (auto-actions, premium connectors) in a private repo / paid plugin.

Files to publish:
- aifinops/gpu_monitor.py
- aifinops/inventory.py
- dashboard GPU panels

Monetization:
- Paid connectors (Ray, Kubeflow, Copilot integration)
- Enterprise policy & SLAs + hosted offering
